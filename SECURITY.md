# Security Policy

## Supported versions

Security fixes are applied to the current `master` branch of Fcitx17. Builds
from older commits should be updated before reporting a potential vulnerability.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option in this repository's
Security tab to submit reports privately. Do not open a public Issue for a
security vulnerability, and do not include private text, clipboard data,
passwords, or tokens in a report.

A good report includes the affected Fcitx17 version or commit, Android version,
reproduction steps, impact, and any proof of concept with sensitive details
redacted. We will acknowledge the report, investigate it, and coordinate a fix
before public disclosure when possible.
